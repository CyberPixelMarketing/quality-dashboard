# لوحة تحكيم الجودة الذكية

لوحة تحكيم لورشة «تحدي الجودة الذكية»: ٣ جولات × ٤ فرق، تقييم بالذكاء الاصطناعي (Gemini) للنص أو لقطة الشاشة، ترتيب مباشر، وتصدير/استيراد CSV و JSON.

## البنية

```
public/          الواجهة (index.html, app.js, styles.css)
api/health.js    حالة الاتصال بالـAI
api/evaluate.js  إرسال التسليم إلى Gemini وإرجاع الدرجات والأدلة
lib/evaluate.js  منطق التقييم المشترك
server.mjs       خادم محلي اختياري للتجربة على جهازك
```

## التشغيل على Vercel

المشروع مربوط بـ GitHub؛ أي `git push` إلى `main` ينشر تلقائياً.

أضف هذه المتغيرات من **Vercel → Project → Settings → Environment Variables** ثم أعد النشر (Redeploy):

| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `GEMINI_API_KEY` | نعم | مفتاح Gemini من https://aistudio.google.com/apikey |
| `ACCESS_CODE` | مُستحسن | رمز يطلبه الموقع من المحكّم قبل أول تقييم، حتى لا يستهلك أي زائر مفتاحك |
| `GEMINI_MODEL` | لا | الافتراضي `gemini-flash-latest` (يشير دائماً لأحدث نموذج Flash) |

## التشغيل محلياً

```powershell
$env:GEMINI_API_KEY="ضع-المفتاح-هنا"
node server.mjs
```
ثم افتح `http://localhost:8787`.

## ملاحظات

- البيانات تُحفظ في متصفح جهاز المحكّم فقط. استخدم «تصدير JSON» للنسخ الاحتياطي و«استيراد JSON» لنقلها لجهاز آخر.
- الصور تُضغط تلقائياً (حد أقصى 1600px) لتناسب حدود Vercel وسعة المتصفح.
- درجة السرعة تُحسب حسب ترتيب أول تقييم لكل فريق في الجولة (20/15/10/5)، ويُعاد حسابها للجميع بعد كل تقييم.
- مفاتيح الإجابة المرجعية قابلة للتعديل من اللوحة؛ عدّلها قبل الورشة لتطابق دليل المدرب.
